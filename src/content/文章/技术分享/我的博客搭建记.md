## 选一套顺眼的主题

挑了很久，最后选了 [Firefly](https://github.com/CuteLeaf/Firefly)。它基于 Astro 构建，换页没有刷新感，亮暗两套主题也都做得比较克制。

安装依赖、改配置、替换头像，基本就成型了：

```bash
pnpm install
pnpm dev
pnpm build
```

## 几个小坑

### 1. 头像不生效

首页 Hero 用的不是 `profileConfig.avatar`，而是它自己的一份图片列表。改配置的时候要两边都看一遍。

### 2. 代码块行号

Expressive Code 默认是关行号的，在 `astro.config.mjs` 里打开：

```js
defaultProps: {
  showLineNumbers: true,
}
```

### 3. 内容目录

文章分类由文件夹决定，把 md 放进 `src/content/文章/<分类>/` 就会自动归到那个分类下。

## 笔记怎么办

Typora 里的笔记不用搬家。打开站内的「笔记」页面，把 md 拖进去就能直接读；想沉淀成正式文章，再点「导出 md」放进 `src/content/文章/` 重新构建就好。
